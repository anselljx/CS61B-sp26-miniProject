# CS61B-sp26-miniProject
使用java编写的CS61B sp26的4个mini Project（proj0，proj1，proj2，proj3）

## 内容
### proj0：粒子模拟器
运行后点击屏幕生成粒子，按住相应的键可生成不同种类的粒子。如：
's'-sand 会掉落
'b'-barrier 不受重力影响
'w'-water 会保持流动
'p'-plant 会不断生长
'f'-fire 摧毁plant
### proj1：链表实现双端队列
### proj2：数组实现双端队列
### proj3：并查集实现渗透模型
点击黑色像素块挖空，默认水分布在上部，判断是否渗透
